Content Decay Monitor

Find the pages that are losing search traffic or going out of date, and which to refresh first. Scoutly reads when each page was last updated and looks for past years in titles and text. Add a Search Console comparison to see which pages are losing clicks and rankings. Run it again later to see what’s changed.

How to export a comparison from Search Console
  1. Open Search Console → Performance → Search results.
  2. Click the Date filter → Compare tab → for example Compare last 3 months to previous period → Apply.
  3. Open the Pages tab, then Export → Download CSV. Drop the .zip here as it is. Nothing you add is stored on Scoutly’s server.
