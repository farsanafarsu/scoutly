SEO glossary: plain-English definitions

SEO comes with a lot of jargon. This glossary explains the technical SEO, link, keyword and AI search terms used across Scoutly, in a sentence or two each.

ABCDGHIKLMNORSTX

A

AEO (answer engine optimization)
Structuring content so that questions are answered clearly and directly, making it easier for answer-oriented search features to understand and use. See AEO and GEO.
Alt text
A text description of an image in the alt attribute. It’s read by screen readers and helps search engines understand images. Decorative images should use an empty alt attribute.
Anchor text
The clickable text of a link. Descriptive anchor text helps visitors and search engines understand what the linked page is about.

B

Backlink
A link from another website to yours. Backlinks help search engines discover pages and understand relationships between sites. See the backlink checker.
Breadcrumb
A navigation trail showing where a page sits in a site’s structure, such as Home / Guides / Redirects. It can be marked up with BreadcrumbList structured data.
Broken link
A link that leads to an error, such as a 404 page, a server error or a domain that no longer resolves. See the broken link checker.

C

Canonical tag
A rel="canonical" link that tells search engines which URL is the preferred version of a page when similar or duplicate versions exist. It’s a strong hint, not a directive.
Core Web Vitals
Google’s user-experience metrics for loading (Largest Contentful Paint), responsiveness (Interaction to Next Paint) and visual stability (Cumulative Layout Shift).
Crawl budget
Roughly, how many URLs a search engine can and wants to crawl on a site in a given period. It mainly matters for very large sites or sites with many low-value URLs.
Crawler
A program that fetches web pages by following links, also called a bot or spider. Search engines use crawlers to discover and revisit pages.
Cumulative Layout Shift (CLS)
A Core Web Vital that measures how much visible content moves unexpectedly while a page loads. A score of 0.1 or less is considered good.

D

Duplicate content
Substantially similar content available at more than one URL. It’s usually handled with canonical tags, redirects or consolidation rather than being a penalty in itself.

G

GEO (generative engine optimization)
Improving content clarity, depth, sources and entity information to support discoverability in search experiences that generate answers. See AEO and GEO.

H

Heading tags
HTML elements from h1 to h6 that structure a page’s content. Clear, descriptive headings help readers scan and help search engines understand topics.
Hreflang
An attribute that tells search engines which language or regional version of a page to show to which users.
HTTP status code
A three-digit code a server returns for each request: 200 for success, 301 for a permanent redirect, 404 for not found and 5xx for server errors.

I

Indexability
Whether a page can be added to a search engine’s index. It depends on factors such as status codes, robots directives and canonical tags.
Interaction to Next Paint (INP)
A Core Web Vital that measures how quickly a page responds to user interactions. 200 milliseconds or less is considered good. It replaced First Input Delay in 2024.
Internal link
A link from one page to another page on the same website. Internal links help visitors navigate and help crawlers discover and understand pages.

K

Keyword difficulty
A third-party estimate of how hard it might be to rank for a keyword. Each provider calculates it differently. See keyword research.
Keyword gap
Keywords that competitors appear for in search results but your site doesn’t. See competitor analysis.

L

Largest Contentful Paint (LCP)
A Core Web Vital that measures how long the largest visible image or text block takes to render. 2.5 seconds or less is considered good.
Link gap
Websites that link to one or more competitors but not to you. Often used to find relevant outreach prospects.

M

Meta description
A short summary of a page in the HTML head. Search engines may show it as the snippet in results, though they often write their own.
Meta robots
A tag or HTTP header (X-Robots-Tag) with instructions such as noindex or nofollow that control how search engines index a page and treat its links.

N

Nofollow
A link attribute (rel="nofollow") suggesting that search engines shouldn’t pass ranking credit through a link. Google treats it as a hint.

O

Orphan page
A page with no internal links pointing to it. Orphan pages are hard for visitors and crawlers to find.

R

Redirect chain
A sequence of more than one redirect between the requested URL and the final page. Chains slow pages down and should usually be collapsed into a single redirect.
Referring domain
A unique website that links to yours. Ten links from one site count as one referring domain.
Robots.txt
A file at the root of a site that tells crawlers which paths they may or may not crawl. Blocking crawling doesn’t always prevent a URL from being indexed.

S

Search intent
The goal behind a search: to learn, find a specific site, compare options or take action.
Search volume
An estimate of how often a keyword is searched in a period, usually per month. Volumes are modeled by third-party providers and vary between them.
Structured data
Code, usually JSON-LD using the schema.org vocabulary, that describes a page’s content in a machine-readable way. It can make pages eligible for rich results but doesn’t guarantee them.

T

Title tag
The <title> element of a page. It’s shown in browser tabs and often used as the clickable headline in search results.

X

XML sitemap
A file listing the URLs you want search engines to discover, optionally with last-modified dates. It helps discovery but doesn’t guarantee indexing.
