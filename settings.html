How to connect

Credentials stay on your computer, in the server

  1. 1. Create an account at dataforseo.com and add credit (DataForSEO bills per request).
  2. 2. Copy your API login and password from the dashboard’s API Access page. The API password is not your account password.
  3. 3. Start Scoutly with them (PowerShell):
    $env:DATAFORSEO_LOGIN = "you@example.com"
$env:DATAFORSEO_PASSWORD = "your-api-password"
python server.py
    or in bash: 
    DATAFORSEO_LOGIN=you@example.com DATAFORSEO_PASSWORD=your-api-password python server.py
  4. 4. Reload this page. The tools marked API in the sidebar turn green when the connection works.
